# CPSP Gestión Front

Frontend del sistema de gestión del Colegio de Psicólogos del Perú (CPSP), desarrollado con Angular 18.

## Tecnologías

- **Angular CLI:** 18.2.21
- **Framework:** Angular 18
- **Lenguaje:** TypeScript
- **Estilos:** HTML y CSS/SCSS

## Requisitos previos

- Node.js compatible con Angular 18.
- npm.
- Angular CLI 18.

## Instalación

Clona el repositorio e instala las dependencias:

```bash
git clone https://github.com/carlos2710/cpsp-gestion-front.git
cd cpsp-gestion-front
npm install
```

## Servidor de desarrollo

Ejecuta:

```bash
ng serve
```

Abre `http://localhost:4200/` en tu navegador. La aplicación se recargará automáticamente cuando modifiques los archivos fuente.

## Compilación

Para generar la compilación del proyecto:

```bash
ng build
```

Los archivos generados estarán en el directorio `dist/`.

## Generación de componentes

Para crear un componente:

```bash
ng generate component nombre-componente
```

También puedes generar servicios, directivas, pipes y otras estructuras compatibles con Angular CLI.

## Pruebas unitarias

Ejecuta las pruebas configuradas en el proyecto:

```bash
ng test
```
